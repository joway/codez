One workspace

Three modes that stay close to the code.

A

Agent

Resume Codex and Claude Code sessions, open tabbed terminals, and track usage without leaving the project.

E

Editor

Navigate the file tree, edit with multi-cursor support, search across files, and jump through the command palette.

D

Diff

Review working-tree changes, inspect commit history, stage paths, write commit messages, and push with system git.

Built for daily use

Fast native UI, practical defaults, no web shell around your editor.

Native rendering

egui and wgpu render through Metal on macOS with a compact, Zed-style interface.

Real terminal panes

PTY-backed terminals support selection, paste, URLs, IME input, and login-shell PATH behavior.

Git-first workflow

Local operations use libgit2 while push shells out to system git so your existing credentials keep working.

Graceful agents

The app works whether Codex, Claude Code, both, or neither are installed.

Install

Build and run locally.

CodeZ is macOS-focused and ships from source today.

cargo run cargo run -- /path/to/project ./scripts/package-macos.sh
